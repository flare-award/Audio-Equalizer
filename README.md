# Audio Equalizer

Веб-плеер с 10-полосным эквалайзером. Загружайте свою музыку (или вставляйте прямую ссылку на аудио или поток) и слушайте её с настройками звука.

## Возможности

- **Библиотека**: перетаскивание файлов на страницу, выбор через диалог, MP3 / WAV / OGG / FLAC / M4A / AAC / OPUS. Файлы обрабатываются локально в браузере и никуда не отправляются.
- **Ссылки**: поддержка прямых ссылок на аудио-файлы и потоки (сервер должен разрешать CORS).
- **Эквалайзер** (Web Audio API), те же частоты, что и в исходном скрипте: 60, 170, 310, 600, 1k, 3k, 6k, 12k, 14k, 16k Гц.
  - Полосы от −12 до +12 дБ: перетаскивание мышью/пальцем, стрелки с клавиатуры, двойной клик для сброса.
  - Пресеты: Плоский, Бас, Рок, Поп, Вокал, Классика, Электро, Высокие, Ночь.
  - Предусилитель, баланс (лево/право), моно-режим, полный выключатель эквалайзера.
- **Проигрыватель**: плейлист, перемешивание, повтор (выкл / весь список / один трек), перемотка, громкость, визуализатор спектра.
- **Настройки сохраняются** в `localStorage` браузера.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | Играть / пауза |
| `←` / `→` | Перемотка на 5 секунд |
